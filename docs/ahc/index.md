# 過去AHCメモ

AHC001〜074 の上位解法と、それが強い理由をまとめた。根拠は出典の記述か、スコアの式や計算量から説明できることに限った。推測には「（これは私の解釈）」のように書き添えた。

各回は要点、問題、上位の解法、なぜ強いか、うまくいかなかったこと、手元で確かめた結果、ほかの問題に使える考え方、出典の順に書いた。型ごとに横断して読むときは [横断メモ](./patterns) を使う。

解説放送は YouTube の字幕を取得できなかったので、放送で使われたスライド（PDF）と解説ページを読んだ。11回分（AHC001・006・015・021・028・032・037・044・050・055・062）は、問題文の生成方法から生成器と採点器を自作し、解法を実装して手元で確かめた。コードと結果は [verify/](https://github.com/tyokousagi/heuristic-tips/tree/main/verify) にある。

番号を押すと各回へ移動し、番号にマウスを乗せると要点が出る。
