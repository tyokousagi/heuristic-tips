# Zobrist hash

Zobrist hashは盤面などの状態を1つの整数にするハッシュです。状態が少し変わったときに、XORだけで値を更新できます。

## 使う場面

ビームサーチで同じ状態を除くときに使います。違う手順で同じ状態に着いた候補を、ハッシュ値の一致で見つけます。

焼きなましで、すでに調べた状態を記録するときにも使えます。

## 考え方

「種類kの物がマスcにある」という事実の1つ1つに、64ビットの乱数を割り当てます。状態のハッシュ値は成り立っている事実の乱数をすべてXORした値です。

XORには2つの性質があります。

- 順番を変えても結果が同じです。違う手順で作った同じ状態が、同じ値になります
- 同じ値を2回XORすると元に戻ります。物を取り除く操作も置く操作と同じXORで表せます

物が1つ動いたときの更新は、動く前の乱数と動いたあとの乱数をXORするだけです。

## ハッシュに入れる情報

盤面のほかに、評価に関係する情報があれば、それもハッシュに入れます。手番、持っている物の数、現在位置などです。入れ忘れると、違う状態が同じとみなされて除かれます。

逆に、区別しなくてよい情報は入れません。入れ替えても結果が同じ要素は、同じ種類として扱います。重要でない要素をハッシュから外すと、実質的に同じ状態をまとめて除けます。

## 衝突

違う状態が同じハッシュ値になることを衝突と呼びます。64ビットの乱数を使えば、1回の実行で扱う状態の数では、衝突はほとんど起きません。衝突しても、よい候補が1つ除かれるだけなので、探索が誤った答えを出すことはありません。

## 重複の判定に使う集合

ハッシュ値を入れる集合には、`std::unordered_set` より、[開番地法のハッシュ集合](/snippets/#hash-set)のほうが速く動きます。ハッシュ値はすでに十分にばらけているので、そのまま表の添字に使えます。
