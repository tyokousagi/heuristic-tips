# Zobrist hash

Zobrist hashは盤面などの状態を1つの整数にするハッシュだ。状態が少し変わったときに、XORだけで値を更新できる。

## 使う場面

ビームサーチで同じ状態を除くときに使う。違う手順で同じ状態に着いた候補を、ハッシュ値の一致で見つける。

焼きなましで、すでに調べた状態を記録するときにも使える。

## 考え方

「種類kの物がマスcにある」という事実の1つ1つに、64ビットの乱数を割り当てる。状態のハッシュ値は成り立っている事実の乱数をすべてXORした値だ。

XORには2つの性質がある。

- 順番を変えても結果が同じだ。違う手順で作った同じ状態が、同じ値になる
- 同じ値を2回XORすると元に戻る。物を取り除く操作も置く操作と同じXORで表せる

物が1つ動いたときの更新は、動く前の乱数と動いたあとの乱数をXORするだけだ。

## ハッシュに入れる情報

盤面のほかに、評価に関係する情報があれば、それもハッシュに入れる。手番、持っている物の数、現在位置などだ。入れ忘れると、違う状態が同じとみなされて除かれる。

逆に、区別しなくてよい情報は入れない。入れ替えても結果が同じ要素は、同じ種類として扱う。重要でない要素をハッシュから外すと、実質的に同じ状態をまとめて除ける。

## 衝突

違う状態が同じハッシュ値になることを衝突と呼ぶ。64ビットの乱数を使えば、1回の実行で扱う状態の数では、衝突はほとんど起きない。衝突しても、よい候補が1つ除かれるだけなので、探索が誤った答えを出すことはない。

## 重複の判定に使う集合

ハッシュ値を入れる集合には、`std::unordered_set` より、[開番地法のハッシュ集合](/snippets/#hash-set)のほうが速く動く。ハッシュ値はすでに十分にばらけているので、そのまま表の添字に使える。
