# ランダム選択できる集合

「条件を満たす要素の中から、ランダムに1つ選ぶ」という処理は、近傍の選び方でよく出てきます。追加、削除、ランダムな取得をすべてO(1)で行える集合を用意しておきます。

## 使う場面

- まだ使っていない要素から1つ選ぶ
- 制約に違反している要素から1つ選ぶ
- 境界に接しているマスから1つ選ぶ

全体からランダムに選んで条件を確かめる方法は、条件を満たす要素が少ないと、ほとんどの試行が無駄になります。条件を満たす要素の集合を持てば、1回で選べます。

## 考え方

2つの配列を持ちます。

- `items`。集合の要素を、順番を気にせずに並べた配列
- `pos`。各要素が `items` の何番目にあるかを表す配列。集合にない要素は −1

追加は `items` の末尾に足します。削除は末尾の要素を消す要素の位置へ移してから、末尾を縮めます。ランダムな取得は`items` の添字を乱数で選びます。

## 差分での更新

集合の中身は、状態が変わるたびに差分で更新します。変更によって条件が変わる要素は、変更した場所の周りに限られることが多いので、そこだけを調べて追加と削除を行います。

集合を更新するのは、変更が受理されたときだけです。

## 使うときの注意

削除を行うと、`items` の中の並びが変わります。`items` を前から順に見ながら削除する処理では、見落としや二重の処理が起きます。順に見る必要があるときは、後ろから見るか、先に別の配列へコピーします。

要素の範囲が0以上n未満の整数でない場合は、整数の番号を振ってから使います。
