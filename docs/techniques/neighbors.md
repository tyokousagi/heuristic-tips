# 近傍カタログ

解の形ごとに、定番の近傍を並べる。新しい問題では、解がどの形にあたるかを考え、ここから最初の近傍を選ぶ。

## 順列

要素を並べる順番が解になる場合だ。

| 近傍 | 内容 |
|---|---|
| swap | 2つの要素の位置を入れ替える |
| 隣接swap | 隣り合う2つを入れ替える。変化が最も小さい |
| insert | 1つの要素を抜いて、別の位置へ入れる |
| 区間の反転 | 連続する区間を逆向きにする。2-optにあたる |
| 区間の移動 | 連続する区間を抜いて、別の位置へ入れる。Or-optにあたる |

順番が時間の流れを表す問題では、離れた位置のswapより、insertや隣接swapのほうが悪化が小さくなる。

## 割り当て

各要素をいくつかのグループのどれかに入れる場合だ。

| 近傍 | 内容 |
|---|---|
| 移動 | 1つの要素を別のグループへ移す |
| 交換 | 違うグループの2つの要素を入れ替える |
| 3つの巡回 | 3つのグループのあいだで要素を順に送る |

グループの大きさに制約がある問題では、移動は制約を破りやすく、交換のほうが受理される。

## 部分集合

要素を使うか使わないかを決める場合だ。

| 近傍 | 内容 |
|---|---|
| 反転 | 1つの要素の使う、使わないを切り替える |
| 入れ替え | 使っている要素を1つ外し、使っていない要素を1つ入れる |

使う数が決まっている問題では、入れ替えを使う。

## 数値

各要素に数値を決める場合だ。

| 近傍 | 内容 |
|---|---|
| 増減 | 値を1だけ、または小さな乱数だけ増減する |
| 再設定 | 値をランダムな値に置き換える |
| 受け渡し | ある要素の値を減らし、別の要素の値を同じだけ増やす |

合計が決まっている問題では、受け渡しを使う。増減の幅を温度や経過時間に合わせて狭める方法もある。

## グリッド

マスごとに状態を決める場合だ。

| 近傍 | 内容 |
|---|---|
| 1マスの変更 | 1つのマスの状態を変える |
| 隣との入れ替え | 隣り合う2マスの状態を入れ替える |
| 境界の移動 | 領域の境界にあるマスを、隣の領域へ移す |
| 小さな範囲の作り直し | 数マスの範囲を、列挙や貪欲法で作り直す |

連結性の制約がある問題では、境界のマスだけを対象にする。

## 配置

長方形や点の位置を決める場合だ。

| 近傍 | 内容 |
|---|---|
| 平行移動 | 1つを少しだけ動かす |
| 辺の伸縮 | 長方形の1辺を伸ばす、または縮める |
| 再配置 | 1つを取り除いて、別の場所に置き直す |
| 位置の交換 | 2つの位置を入れ替える |

重なりを許さない問題では重なりを押しのける処理を近傍に含めるか、重なりをペナルティにする。

## 木とグラフ

| 近傍 | 内容 |
|---|---|
| 親の付け替え | 1つの頂点の親を、別の頂点に変える |
| 辺の入れ替え | 辺を1本外して、別の辺を足す |
| 経路の引き直し | 2点間の経路を外して、別の経路でつなぎ直す |

## 共通の工夫

どの形でも、次の工夫が使える。

- 複数の近傍を混ぜ、選ぶ確率を調整する
- 変更する要素を、問題のある場所から優先して選ぶ
- 解の一部を取り除いて、貪欲法で作り直す

近傍の考え方は[焼きなましの近傍設計](/methods/sa-neighbor)に、実例は[焼きなましの近傍](/tips/sa-neighbor)にある。
