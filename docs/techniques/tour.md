# 巡回路の近傍

決まった点をすべて回る順番を決める問題は、巡回セールスマン問題の形になる。定番の近傍があり、差分をO(1)で計算できる。

## 2-opt

巡回路から2本の辺を外し、あいだの区間を逆向きにしてつなぎ直す。配列の上では区間の反転になる。

変わる辺は2本だけなので、差分は4つの距離で求まる。区間の中の辺は向きが逆になるだけで、距離が対称なら長さは変わらない。

反転そのものは、区間の長さに比例した時間がかかる。受理されたときにだけ行う。

## Or-opt

連続する1〜3個の点を抜き出し、別の場所へ入れ直す。向きを逆にして入れるバージョンもある。2-optでは直しにくい、数個の点が離れた場所に取り残された形を直せる。

## 近い点だけを相手にする

2-optの相手をすべての点からランダムに選ぶと、ほとんどの試行が大きな悪化になる。各点について、近い順に10個ほどの点の一覧を前計算し、相手をその中から選ぶ。受理される割合が上がる。

## 距離が対称でない場合

行きと帰りで距離が違う問題では、区間を反転すると区間の中の長さも変わる。2-optの差分をO(1)で求められない。

区間の向きを変えないOr-optや、2つの点の入れ替えは、対称でない距離でもそのまま使える。

## 始点と終点が決まっている場合

始点から終点へ行く経路の問題では、巡回路の最後から最初へ戻る辺がない。スニペットの関数は閉じた巡回路を前提にしている。始点と終点を固定する場合は、その2点を動かさないように添字の範囲を制限し、戻る辺の長さを0とみなす。

## 巡回路以外の要素がある場合

回る順番のほかに、どの点を回るか、どこで補給するかなども決める問題がある。その場合は、順番を変える近傍に加えて、点の追加、削除、入れ替えの近傍を作る。

順番を決めると残りが最適に決まる問題なら、順番だけを焼きなまし、残りはDPで求める方法もある。

## 局所解から出る方法

2-optとOr-optの焼きなましで足りないときは、4本の辺をつなぎ替えるdouble bridgeを低い確率で混ぜる。巡回路を3か所で切って4つの区間に分け、2番目と3番目の区間を入れ替える操作だ。
