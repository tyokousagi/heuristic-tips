# 乱数

ヒューリスティックでは1回の実行で数百万回から数千万回の乱数を使う。速い生成器を使い、範囲の変換も軽い方法で行う。

## 生成器

標準の `mt19937` でも正しく動くが、xorshiftのほうが速く、コードも短く済む。C言語の `rand()` は遅く、範囲も狭いので使わない。

## 範囲の変換

0以上n未満の整数は `next() % n` でも作れる。剰余は遅い演算なので、スニペットでは上位32ビットにnを掛けて32ビット右へシフトする方法を使っている。

0以上1未満の実数は上位53ビットを取り出して2の53乗で割る。

## シードの扱い

シードを固定すると、同じ入力に対して同じ結果が出る。変更の前後を比べるときも、不具合を再現するときも、結果が毎回同じであることが前提になる。

温度を経過時間で決める焼きなましは、シードを固定しても結果が毎回少し変わる。再現が必要なときは、時間の代わりに反復回数で進み具合を決めるバージョンに切り替える。

多点スタートのように同じ処理を何度も実行する場合は、実行ごとに違う乱数が使われることを確かめる。生成器を使い回していれば、自然に違う列になる。

## 重みつきの選択

重みに比例した確率で要素を選ぶ処理は、近傍の選び方でよく使う。

- 要素が少ないなら、重みの合計に乱数を掛け、前から順に引いていく
- 重みが変わらないなら、累積和を作って二分探索で選ぶ
- 近傍の種類を選ぶだけなら、乱数を100で割った余りなどで分岐する

## 順列のシャッフル

配列をランダムに並べ替えるには、後ろからi番目の要素を、0以上i以下のランダムな位置の要素と入れ替えていく。`std::shuffle` に自作の生成器を渡すこともできる。その場合は、生成器に `operator()` と `min`、`max` を足す。
