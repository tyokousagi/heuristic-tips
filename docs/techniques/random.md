# 乱数

ヒューリスティックでは1回の実行で数百万回から数千万回の乱数を使います。速い生成器を使い、範囲の変換も軽い方法で行います。

## 生成器

標準の `mt19937` でも正しく動きますが、xorshiftのほうが速く、コードも短く済みます。C言語の `rand()` は遅く、範囲も狭いので使いません。

## 範囲の変換

0以上n未満の整数は`next() % n` でも作れます。剰余は遅い演算なので、スニペットでは上位32ビットにnを掛けて32ビット右へシフトする方法を使っています。

0以上1未満の実数は上位53ビットを取り出して2の53乗で割ります。

## シードの扱い

シードを固定すると、同じ入力に対して同じ結果が出ます。変更の前後を比べるときも、不具合を再現するときも、結果が毎回同じであることが前提になります。

温度を経過時間で決める焼きなましは、シードを固定しても結果が毎回少し変わります。再現が必要なときは、時間の代わりに反復回数で進み具合を決めるバージョンに切り替えます。

多点スタートのように同じ処理を何度も実行する場合は、実行ごとに違う乱数が使われることを確かめます。生成器を使い回していれば、自然に違う列になります。

## 重みつきの選択

重みに比例した確率で要素を選ぶ処理は、近傍の選び方でよく使います。

- 要素が少ないなら、重みの合計に乱数を掛け、前から順に引いていきます
- 重みが変わらないなら、累積和を作って二分探索で選びます
- 近傍の種類を選ぶだけなら、乱数を100で割った余りなどで分岐します

## 順列のシャッフル

配列をランダムに並べ替えるには、後ろからi番目の要素を、0以上i以下のランダムな位置の要素と入れ替えていきます。`std::shuffle` に自作の生成器を渡すこともできます。その場合は、生成器に `operator()` と `min`、`max` を足します。
