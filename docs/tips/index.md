# tips集の入口

公開されている解説、参加記、手法別の記事から集めたtipsを、カテゴリごとに載せています。

<TipsIndex />

## tipsの読み方

1件のtipsは見出し、短い説明、出典の3つでできています。説明はこのサイトで書き直した文章です。元の記事にはくわしい背景や図があるので、気になったtipsは出典を読んでください。

同じ内容が複数の資料にある場合は1件にまとめ、出典を並べています。資料によって勧める内容が違う場合は、両方を載せて条件の違いを書いています。

効果が問題によって変わるtipsも削らずに載せています。その場合は、どんな問題で使えるかを説明に書いています。

調べた資料は[出典一覧](/sources)にまとめています。
