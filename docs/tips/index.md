# tips集の入口

公開されている解説、参加記、手法別の記事から集めたtipsを、カテゴリごとに載せている。

<TipsIndex />

## tipsの読み方

1件のtipsは見出し、短い説明、出典の3つでできている。説明は元の記事を自分の言葉で書き直した文章だ。元の記事にはくわしい背景や図があるので、気になったtipsは出典を読む。

同じ内容が複数の資料にある場合は1件にまとめ、出典を並べている。資料によって勧める内容が違う場合は、両方を載せて条件の違いを書いている。

効果が問題によって変わるtipsも削らずに載せている。その場合は、どんな問題で使えるかを説明に書いている。

調べた資料は[出典一覧](/sources)にまとめている。
