# ヒューリスティックtips

AtCoder Heuristic Contest（AHC）の human only 部門に出るための自分用の資料だ。ヒューリスティックのtips、過去AHCの解法、C++の実装例をまとめた。

tips集には公開されている解説や参加記から集めたtipsを出典つきで載せた。

## human only部門で使うときの注意

スニペットをコンテストで使うときは、提出コードの該当部分に公開先のURLを書く必要がある。詳しいルールと手順は[サイトの使い方とルール](/guide/about)にまとめた。
