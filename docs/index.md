# ヒューリスティックtips

AtCoder Heuristic Contest（AHC）のhuman only部門に向けて、ヒューリスティックのtipsとC++の実装例をまとめたサイトです。

tips集には公開されている解説や参加記から集めたtipsを、出典つきで載せています。

## 目的別の入口

| やりたいこと | 見るページ |
|---|---|
| コンテスト中に手法を決める | [手法の選び方](/guide/choosing) |
| 焼きなましのスコアを上げる | [焼きなましの近傍](/tips/sa-neighbor)、[焼きなましの温度と受理](/tips/sa-temp) |
| ビームサーチを書く | [ビームサーチの基本](/methods/beam-basic)、[ビームサーチのtips](/tips/beam) |
| すぐ貼れるコードを探す | [スニペット一覧](/snippets/) |
| 提出の前に確認する | [提出前チェックリスト](/workflow/checklist) |

## human only部門での使い方

スニペットをコンテストで使うときは、提出コードの該当部分に公開先のURLを書く必要があります。くわしくは[サイトの使い方とルール](/guide/about)を読んでください。
