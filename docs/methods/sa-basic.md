# 焼きなましの基本

焼きなまし法は山登り法に「悪くなる変更も確率的に採用する」規則を足した手法です。局所解から出られるので、多くの問題で山登り法より高いスコアになります。

## 使う場面

解の一部を少し変える操作があり、その差分を速く計算できる問題で使います。割り当て、順列、配置を決める問題が代表です。

少し変えると解が成り立たなくなる問題には向きません。その場合は、解の表し方を変えるか、ビームサーチを検討します。

## 考え方

スコアを最大化する場合、変更によるスコアの差分をΔ、温度をTとして、次の確率で変更を採用します。

- Δが0以上なら必ず採用する
- Δが負なら確率 e^(Δ/T) で採用する

温度は時間とともに下げます。序盤は温度が高く、悪くなる変更も多く採用されるので、解が広い範囲を動きます。終盤は温度が低く、山登り法に近い動きになります。

探索の途中でスコアが下がることがあるので、それまでに見つけた最良の解を別に保存し、最後にそれを出力します。

最小化の問題ではスコアの符号を反転して最大化として扱うと、式を取り違えにくくなります。

## よくある失敗

最後の状態をそのまま出力する誤りが、とても多くあります。必ず最良の解を出力します。

温度がスコアの規模に合っていないと、焼きなましになりません。温度が低すぎると山登り法と同じになり、高すぎるとランダムな変更を繰り返すだけになります。受理された回数を出力して確かめます。
