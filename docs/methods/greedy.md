# 貪欲法

貪欲法はその場で最もよい選択肢を選び続けて解を作る手法です。最初に書く解法として使い、ほかの手法の初期解や部品としても使います。

## 使う場面

問題文を読んだ直後に、最初の解法として書きます。動かして結果を見ると、問題のどこが難しいのかがわかります。

焼きなまし法の初期解、ビームサーチの評価関数のもと、モンテカルロ法のプレイアウトにも、貪欲法をそのまま使えます。

## 考え方

貪欲法の質は選択肢を比べる基準で決まります。最初は「最も近い」「最もコストが小さい」といった単純な基準で構いません。

基準を改良する方法は主に3つあります。

- 得られる価値を、使う資源の量で割った値で比べる
- 不利になりそうな選択肢を、最初から候補から外す
- 処理する順番を変える

AHC041の解説では、処理する順番を変えるだけで順位が大きく上がっています。

基準に重みやしきい値が入ったら、それをパラメータにして調整できます。パラメータが多い貪欲法を焼きなましで調整し、それだけで上位に入った例もあります。

## よくある失敗

貪欲法は先のことを考えないので、後半に不利な選択肢しか残らないことがあります。上の例でも、最後に遠くの都市を回収する長い移動が残ります。ビジュアライザで後半の動きを見ると、この種の問題点に気づけます。

最初から完璧な基準を作ろうとして時間を使いすぎることも、よくある失敗です。まず単純なバージョンを動かします。
