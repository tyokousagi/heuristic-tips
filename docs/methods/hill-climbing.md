# 山登り法

山登り法は解を少し変えて、よくなったら採用することを繰り返す手法だ。焼きなまし法のもとになるので、先にこの形を完成させる。

## 使う場面

解の一部を変える操作を作れる問題で使う。焼きなまし法を書く前の段階として実装すると、差分計算や時間の管理を、受理の判定と切り離して確かめられる。

評価関数に局所解がない問題では、山登り法のほうが焼きなまし法より速く収束する。

## 考え方

必要な部品は4つだ。

- 初期解
- 解を少し変える操作。近傍と呼ぶ
- 変えたときのスコアの差分を求める計算
- 制限時間まで繰り返すループ

近傍は、変更のあとも解が成り立つ形にする。差分は変わった部分だけを計算して求める。スコアを最初から計算し直すと、試せる回数が大きく減る。

同じスコアになる変更を採用するかどうかで、結果が変わることがある。採用すると、スコアを保ったまま解が動き、別の改善が見つかりやすくなる。

## よくある失敗

どの変更でもよくならない解に着くと、そこで改善が止まる。この解を局所解と呼ぶ。改善が早い時点で止まる場合は、[焼きなまし法](/methods/sa-basic)に進む。

差分計算の誤りにも注意する。差分を足していったスコアと、最初から計算したスコアを、最後に比べて確かめる。
