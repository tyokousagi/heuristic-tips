# モンテカルロ法

モンテカルロ法はわからない部分を乱数で決めたシミュレーションを何度も行い、結果の平均で行動を選ぶ手法です。

## 使う場面

これから来る入力がランダムに決まる問題で使います。次に何が来るかわからないまま、いま何をするかを決める問題です。

途中の状態のよさを評価関数で表しにくい問題でも使えます。シミュレーションを最後まで進めれば、最終的なスコアという確かな値で比べられるからです。

## 考え方

1. いま選べる行動を列挙します。
2. 行動ごとに、その行動を選んだあとの続きを最後までシミュレーションします。これをプレイアウトと呼びます。
3. プレイアウトを何度も行い、最終スコアの平均を求めます。
4. 平均が最も高い行動を選びます。

プレイアウトの中では、2種類のことを決める必要があります。

- 自分では決められないこと。乱数で決めます
- 自分で決められること。ルールや貪欲法で決めます

自分の行動までランダムにすると、現実には起きない悪い展開が多く混ざり、評価が不正確になります。thunderさんのAHC015の例では、行動をルールで決める形に変えると、スコアが大きく上がりました。

## 精度を上げる工夫

プレイアウトの回数を4倍にすると、平均のばらつきは約半分になります。プレイアウトを速くすることが、精度に直接つながります。

行動どうしを比べるときは、どの行動にも同じ乱数の列を使います。運の差がなくなり、少ない回数でも正しく比べられます。

見込みのない行動に時間を使わないように、一定の回数ごとに成績の悪い半分を捨てる方法があります。

プレイアウトの前に、軽い評価関数で行動の候補を絞ることもできます。

## 時間の配分

ターンごとに行動を決める問題では、残り時間を残りのターン数で割った値を、そのターンの持ち時間にします。

序盤の行動のほうが結果への影響が大きい問題では、序盤に多くの時間を配ります。

## よくある失敗

プレイアウトのたびに状態を深くコピーしていると、回数を稼げません。必要な部分だけをコピーするか、変更を巻き戻す形にします。

基準の状態を参照のまま書き換えてしまい、次の行動の評価が狂う誤りもあります。行動ごとに、基準の状態のコピーから始めます。
