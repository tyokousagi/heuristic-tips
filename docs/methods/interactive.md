# インタラクティブ問題の推定

見えない値を、ノイズのある観測から推定する問題がある。観測のたびに推定を更新し、推定した値を使って行動を決める。

## 使う場面

質問や行動の結果として、真の値にノイズを加えた値が返ってくる問題で使う。AHC003、AHC022、AHC030、AHC040がこの種類だ。

## ベイズ推定の考え方

見えない値についての仮説を複数考え、それぞれの確からしさを確率で持つ。観測のたびに、次の式で確率を更新する。

```
新しい確率 ∝ 前の確率 × その仮説のもとで観測値が得られる確率
```

右辺の2つ目の値を尤度と呼ぶ。尤度は問題文に書かれたノイズの分布から計算する。

最初の確率は入力の生成方法から決める。どの仮説も同じ確率で生成されるなら、すべて同じ値にする。

## 尤度の計算

観測値が「真の値に正規分布のノイズを加えて四捨五入した値」なら、観測値の前後0.5の区間に入る確率が尤度だ。[正規分布の確率](/snippets/#normal-prob)の `rounded_normal_prob` で計算できる。

観測値に下限があり、下限より小さい値が下限に切り上げられる場合は、下限のときだけ区間が片側に無限に伸びる。

観測を重ねると、尤度の積はとても小さい値になる。対数をとって足し算で計算し、確率に戻すときは最大値を引いてから指数をとる。同じスニペットの `log_likelihood_to_prob` がこの処理だ。

## 仮説の持ち方

仮説の数によって、持ち方を変える。

| 仮説の数 | 持ち方 |
|---|---|
| 数万まで | すべて列挙して確率を持つ |
| 列挙できない | 尤度の高い仮説を焼きなましで集め、プールとして持つ |
| 連続値が多数 | 平均と共分散で表す。多変量正規分布として更新する |
| 式で表せない | MCMCでサンプルを取る |

## 質問の選び方

どの質問をするかを選べる問題では、推定の不確かさが最も減る質問を選ぶ。不確かさはエントロピーで測れる。質問で得られる情報の量を質問のコストで割った値が、最大になる質問を選ぶ。

質問をランダムに選ぶだけの実装でも、推定が正しければ動く。まずその形で動かし、質問の選び方はあとで改善する。

## 推定と行動の両立

行動の結果が観測になる問題では、スコアのための行動と、情報を集めるための行動のバランスをとる。推定が不確かな選択肢を少し有利に評価すると、情報の少ない部分が自然に調べられる。この補正は序盤に大きく、終盤に小さくする。

## よくある失敗

尤度の式の誤りは、プログラムが動いてしまうので気づきにくい失敗だ。真の値がわかっている手元のテストで、推定が真の値に近づくことを確かめる。推定している確率の変化を可視化すると、誤りを見つけやすくなる。
