# 焼きなましの近傍設計

焼きなまし法の成績は近傍の作り方で大きく変わります。初期解やスコア計算は参加者のあいだで似た形になり、差が出るのは近傍です。

## よい近傍の条件

gasinさんは、近傍が満たすべき性質を3つ挙げています。

- 差分の計算が軽い
- どの解にも近傍を繰り返して到達できる
- 変更によるスコアの変化が極端でない

3つ目が最も重要です。よい解から移る先のほとんどが大きく悪い解だと、受理される変更がなくなり、探索が進みません。

## 近傍を作る手順

1. 最も単純な近傍を1つ作ります。値を1つ変える、2つを入れ替える、1つを別の場所へ移す、などです。
2. 動かして、受理された回数と最終スコアを見ます。
3. ビジュアライザで結果を見て、今の近傍では直せない箇所を探します。
4. その箇所を直せる近傍を足します。

近傍の種類ごとに、試した回数と受理された回数を記録します。受理されない近傍は選ぶ確率を下げるか、作り方を見直します。

## 近傍を大きくする場合

要素どうしが強く関係している問題では、1つだけ変えても残りと合わず、受理されません。関係の強い要素をまとめて変える近傍を作ります。

大きな近傍は、スコアが大きく悪くなりやすいという欠点があります。解の一部を取り除いて貪欲法で作り直すと、大きく変えながら悪化を小さくできます。この近傍は破壊再構築と呼ばれます。

## 近傍の選び方

変更する場所をランダムに選ぶと、改善の見込みがない場所にも試行を使います。目標との差が大きい要素を高い確率で選ぶ、改善しないとわかる変更を先に外す、といった工夫で無駄を減らせます。

貪欲に選びすぎると局所解に入りやすくなるので、乱数を残します。

## よくある失敗

近傍が足りず、探索できる範囲が一部に限られていることがあります。焼きなましはそれらしく動くので、気づきにくい失敗です。今の近傍では到達できない解がないかを、具体的な解を思い浮かべて確かめます。
