# ビームサーチの基本

ビームサーチは、解を1手ずつ組み立てながら、各段階で評価のよい状態を決まった数だけ残す手法です。残す数をビーム幅と呼びます。ビーム幅が1なら貪欲法と同じです。

## 使う場面

操作を順番に積み上げる問題で、途中の状態のよさを評価値で比べられるときに使います。盤面を操作するパズルや、ターンごとに行動を決める問題が代表です。

途中の状態を比べにくい問題には向きません。同じ深さの状態がどれも同じ評価値になるようなら、評価関数を作り直すか、焼きなまし法を検討します。

## 考え方

1. 初期状態だけを持つ集合から始めます。
2. 集合の中のすべての状態について、次の1手の候補を列挙します。
3. 候補を評価値の順に並べ、上位からビーム幅の数だけ残します。同じ状態は1つだけ残します。
4. 決めた手数に達するまで、2と3を繰り返します。
5. 最後に残った状態のうち最もよいものを選び、そこまでの手順を出力します。

候補を列挙するときは、状態をコピーせず、遷移後の評価値だけを計算します。状態をコピーするのは、残すと決まった候補だけにします。

手順は状態ごとに持たずに、親をたどれる木として1か所にまとめます。状態をコピーするたびに手順までコピーすると、深くなるほど遅くなります。

## ビーム幅の決め方

ビーム幅を大きくすると、解はよくなり、時間は長くかかります。制限時間に収まる最大の幅を使うのが基本です。

実行時間は入力によって変わります。固定の幅では、時間が余るケースと足りないケースが出ます。経過時間を見ながら幅を増減させる方法と、chokudaiサーチに変える方法があります。

## よくある失敗

重複を除かないと、順番だけが違う同じ状態でビームが埋まります。その場合、結果は貪欲法とほとんど変わりません。状態のハッシュ値で重複を除きます。

評価値が同じ候補が多いと、候補の並び順で結果が決まります。同点の候補をシャッフルするか、評価関数に差がつく項を足します。
