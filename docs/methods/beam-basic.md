# ビームサーチの基本

ビームサーチは、解を1手ずつ組み立てながら、各段階で評価のよい状態を決まった数だけ残す手法だ。残す数をビーム幅と呼ぶ。ビーム幅が1なら貪欲法と同じだ。

## 使う場面

操作を順番に積み上げる問題で、途中の状態のよさを評価値で比べられるときに使う。盤面を操作するパズルや、ターンごとに行動を決める問題が代表だ。

途中の状態を比べにくい問題には向かない。同じ深さの状態がどれも同じ評価値になるようなら、評価関数を作り直すか、焼きなまし法を検討する。

## 考え方

1. 初期状態だけを持つ集合から始める。
2. 集合の中のすべての状態について、次の1手の候補を列挙する。
3. 候補を評価値の順に並べ、上位からビーム幅の数だけ残す。同じ状態は1つだけ残す。
4. 決めた手数に達するまで、2と3を繰り返す。
5. 最後に残った状態のうち最もよいものを選び、そこまでの手順を出力する。

候補を列挙するときは、状態をコピーせず、遷移後の評価値だけを計算する。状態をコピーするのは、残すと決まった候補だけにする。

手順は状態ごとに持たずに、親をたどれる木として1か所にまとめる。状態をコピーするたびに手順までコピーすると、深くなるほど遅くなる。

## ビーム幅の決め方

ビーム幅を大きくすると、解はよくなり、時間は長くかかる。制限時間に収まる最大の幅を使うのが基本だ。

実行時間は入力によって変わる。固定の幅では、時間が余るケースと足りないケースが出る。経過時間を見ながら幅を増減させる方法と、chokudaiサーチに変える方法がある。

## よくある失敗

重複を除かないと、順番だけが違う同じ状態でビームが埋まる。その場合、結果は貪欲法とほとんど変わらない。状態のハッシュ値で重複を除く。

評価値が同じ候補が多いと、候補の並び順で結果が決まる。同点の候補をシャッフルするか、評価関数に差がつく項を足す。
