# 手法の選び方

主な手法は解を少しずつ変える手法と、解を端から組み立てる手法の2つに分かれます。前者が山登り法と焼きなまし法、後者が貪欲法とビームサーチです。

## 最初に考える問い

解の一部を少しだけ変えたとき、スコアも少しだけ変わるかどうかを考えます。

変わる量が小さく、変えたあとの解も制約を満たすなら、焼きなまし法が第一の候補です。割り当て、順列、配置を決める問題の多くがこれにあたります。

操作を順番に積み上げる問題で、途中の操作を1つ変えるとあとの操作が成り立たなくなるなら、ビームサーチが候補です。盤面を操作するパズルや、ターンごとに行動を決める問題がこれにあたります。

## 手法ごとの条件

| 手法 | 向く条件 | 向かない条件 |
|---|---|---|
| 貪欲法 | 最初の解法、ほかの手法の部品 | 先の手を見ないと損をする問題 |
| 焼きなまし法 | 小さな変更で差分を速く計算できる | 少し変えると解が成り立たなくなる |
| ビームサーチ | 途中の状態を評価値で比べられる | 途中の状態のよさを測りにくい |
| chokudaiサーチ | ビーム幅の調整に時間をかけられない | 多様性が要らない問題 |
| モンテカルロ法 | これから来る入力がランダム | プレイアウトが遅い問題 |
| ベイズ推定 | 見えない値をノイズつきで観測する | 観測が正確な問題 |

## 焼きなましとビームサーチで迷う場合

どちらでも解けそうな問題は多くあります。hakomoさんは、完成した解を変える手法のほうが、どの要素も変更でき、正確なスコアで比べられるので強い傾向にあるとしています。

一方でthunderさんは、行動の順序で盤面が大きく変わる問題では、ビームサーチが有利だとしています。

迷ったら、焼きなまし法の近傍を具体的に考えます。変更のあとも制約を満たす近傍を思いつき、差分を速く計算できそうなら、焼きなまし法から始めます。思いつかないなら、ビームサーチの評価関数を考えます。

## 組み合わせ

1つの手法だけで解く必要はありません。よくある組み合わせを挙げます。

- 貪欲法やビームサーチで初期解を作り、焼きなまし法で改善する
- 解の一部を焼きなまし、残りをDPや貪欲法で求める
- ルールで決めた操作をプレイアウトに使い、モンテカルロ法で行動を選ぶ
- 推定で見えない値を求め、その値を使って探索する

それぞれの手法の解説はサイドバーの「手法」から読めます。順序を決めて残りをDPで解く方法は、[その他の探索](/tips/search-other)に実例があります。
