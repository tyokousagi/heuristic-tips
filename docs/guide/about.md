# サイトの使い方とルール

このサイトは、AtCoder Heuristic Contest（AHC）のhuman only部門に出る人が、コンテストの前に読み、コンテスト中にコードを取り出すための資料です。

## サイトの構成

[tips集](/tips/)には、公開されている解説や参加記から集めたtipsを、出典つきで載せています。手法ごとの考え方は「手法」と「テクニック」のページにまとめています。貼って使えるコードは[スニペット一覧](/snippets/)にあります。

## 文章とコードの作り方

このサイトの文章とコードは、生成AIを使って作成しています。tipsの内容は出典の資料にもとづいていますが、説明の文章はこのサイトで書き直したものです。コードはテストでコンパイルと動作を確かめています。

## human only部門のルール

長期AHCのhuman only部門には、生成AIの利用についてのルールがあります。2026年10月26日版のルールで確認した内容は次のとおりです。

- コンテストの開始前に生成AIで作ったコードは使えます。開始前に作られたとわかるように事前に公開し、提出コードの該当する部分に公開先のURLを書く必要があります。
- コンテスト中に、解法や問題の理解について生成AIに質問することはできません。生成AIに解説を出力させることもできません。
- コード補完の機能は、ルールが名前を挙げているものだけ使えます。同じ製品のチャットやエージェントの機能は使えません。
- 検索結果に表示されるAIによる概要は、見ないように求められています。

ルールは改定されることがあります。出る前に、必ず[公式のルール](https://info.atcoder.jp/entry/long-ahc-llm-rules-ja)の最新版を読んでください。

## スニペットを使うときの手順

スニペットをコンテストで使う場合は、次の3つを守ってください。

1. コンテストの開始前に、このサイトを公開しておきます。
2. スニペットの1行目にある公開先URLのコメントを、消さずに提出コードへ貼ります。
3. 貼ったあとで書き換えた部分は、自分の手で書きます。

## 確認できていない点

コンテスト中に、生成AIが開始前に書いた解説の文章を読んでよいかどうかは、ルールに書かれていませんでした。このサイトのtips集や手法のページがこれにあたります。心配な場合は、解説のページはコンテストの前に読むだけにするか、AtCoderに問い合わせてください。
