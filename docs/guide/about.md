# サイトの使い方とルール

このサイトは、自分が AtCoder Heuristic Contest（AHC）の human only 部門に出るための資料だ。コンテストの前に読み、コンテスト中はコードを取り出すのに使う。

## サイトの構成

[tips集](/tips/)には公開されている解説や参加記から集めたtipsを、出典つきで載せた。AHC001〜074 の上位解法と、それが強い理由は[過去AHCメモ](/ahc/)にまとめた。手法ごとの考え方は「手法」と「テクニック」のページに、貼って使えるコードは[スニペット一覧](/snippets/)にある。

## 文章とコードの作り方

このサイトの文章とコードは、生成AIを使って作った。tipsの内容は出典の資料にもとづいていて、説明の文章は資料を写さずに書き直している。コードはテストでコンパイルと動作を確かめた。過去AHCの解法の一部は手元で実装して効果を確かめた（[verify/](https://github.com/tyokousagi/heuristic-tips/tree/main/verify)）。

## human only部門のルール

長期AHCの human only 部門には、生成AIの利用についてのルールがある。2026年10月26日版のルールで確認した内容は次のとおりだ。

- コンテストの開始前に生成AIで作ったコードは使える。開始前に作られたと分かるように事前に公開し、提出コードの該当する部分に公開先のURLを書く必要がある。
- コンテスト中に、解法や問題の理解について生成AIに質問することはできない。生成AIに解説を出力させることもできない。
- コード補完の機能は、ルールが名前を挙げているものだけ使える。同じ製品のチャットやエージェントの機能は使えない。
- 検索結果に表示されるAIによる概要は、見ないよう求められている。

ルールは改定されることがあるので、出る前に必ず[公式のルール](https://info.atcoder.jp/entry/long-ahc-llm-rules-ja)の最新版を読む。

## スニペットを使うときの手順

スニペットをコンテストで使うときは、次の3つを守る。

1. コンテストの開始前に、このサイトを公開しておく。
2. スニペットの1行目にある公開先URLのコメントを、消さずに提出コードへ貼る。
3. 貼ったあとで書き換えた部分は、自分の手で書く。

## 確認できていない点

生成AIが開始前に書いた解説の文章を、コンテスト中に読んでよいかどうかは、ルールに書かれていなかった。このサイトのtips集、過去AHCメモ、手法のページがこれにあたる。不安なら、解説のページはコンテストの前に読むだけにするか、AtCoderに問い合わせる。
