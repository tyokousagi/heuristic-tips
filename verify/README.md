# 過去AHCの解法の検証

過去AHCメモに書いた解法と「なぜ強いか」が正しいかを、手元で実装して確かめたコードを置いた。
生成器と採点器は問題文の「入力生成方法」と「得点」から自作した（公式ツールは使っていない）。
どのファイルも1つで完結していて、生成・解法・採点をまとめて行い、解法ごとの平均点を出す。

```bash
g++ -std=c++20 -O2 verify/ahc050.cpp -o ahc050 && ./ahc050
```

引数はファイル先頭のコメントに書いた（ケース数、試行回数、秒数など）。
シードは固定なので、同じ引数なら同じ結果になる（秒数で区切るものは実行環境で少し変わる）。
